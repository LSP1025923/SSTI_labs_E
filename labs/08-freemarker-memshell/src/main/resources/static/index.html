多租户 SaaS 后台 ｜ 运营自助改模板，前台实时预览 ｜ v1.4.2
⚠ 出网已切断（no-egress）
容器内 iptables 丢弃 eth0 上的出向 TCP SYN 与 UDP/53：反弹 shell、DNSLog、任何主动外连都不可用。 只有「客户端 → 服务端」这条入向 HTTP 通道是通的。想拿数据，得让 shell 住在 JVM 内存里。
目标：读取容器内的 /flag。站点不提供任何读 flag 的接口，必须真的打通一条 RCE 链。

① FreeMarker 主题预览（漏洞点 1）

运营在编辑区写 FreeMarker 片段，服务端用 new Template(StringReader) 直接渲染。 为了让预览和线上渲染一致，类解析器被配成了 UNRESTRICTED。

接口：GET /theme/preview?template=<ftl>&theme=<name>
数据模型：theme_name / now / site / servletContext（GET /api/theme-vars）

② Thymeleaf 模板预览（漏洞点 2）

主题模板按名字取：控制器把 "theme/" + theme 直接当视图名返回， 交给 Thymeleaf 解析。Thymeleaf 3 会对视图名做 __${...}__ 预处理。

接口：GET /theme/thymeleaf?theme=<name>
